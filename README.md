# dsh-bagu

**查一段话是不是「谁都能说」。**

核心判断只有一句：

> 八股的问题不是礼貌，是可替换。谁都能说的话，慢慢就没人想看了。

一句话换个人说，还成不成立？成立，就是八股。

## 它做什么、不做什么

**做：** 把一段话拆成几个可测的指标，各算各的给出来，再加一组「要你自己答」的问句。

**不做：**

- 不给「人味分」这种单一数字。分数会让人只盯数字，不看句子。
- 不自动改写。改要人改，工具只把材料摆出来。
- 不硬塞语气词、不补错别字。加进去的是另一种假。

## 装了以后

系统提示里多一节「说话的念头」，两个只读工具：

```js
bagu_check({ text: "……" })   // 指标 + 判档 + 问句
bagu_ask({ text: "……" })     // 只要问句，不要结论
```

## 指标

| 指标 | 看什么 | 为什么 |
|---|---|---|
| 具体性 | 每百字几个数字 / 时间 / 经历 / 原话 / 名字 | 只有真的在说事的人才给得出 |
| 抽象度 · 评价度 | 意义、价值、本质 / 重要、关键、深刻 | 说得越多，越是在说事之外撑场面 |
| 留白词 | 好像、应该、大概、可能 | 一个都没有 = 句句在下断言 |
| 结构腔 | 不是X而是Y、先…再…、三段并列、破折号 | 密度超标才报 |

## 输出长什么样

```text
[判断] 换谁都行 · 把这些句子搬到另一个人嘴里，读起来不会有差别。
[文体] 解释 · 同文体结构腔基线 2/千字
[具体] 每百字 0 个具体物（数字/时间/经历/原话/名字）· 抽象词 1 · 评价词 1
[留白] 0 个（0/千字） —— 一个都没有，等于句句在下断言
[结构腔] 49.2/千字 · 基线的 37.8 倍 · 同百字最多 1 种句式
[逐处]
  · 首先/其次/综上 ×2：「首先」「其次」
[要你自己答]
  - 开头就在总结（综上所述）。删掉这一句，下面的东西还站得住吗？
  - 一个「好像 / 应该 / 大概」都没有。全篇没有一处不确定，是真的都想清楚了？
[看不见] 这一步只认字面和句式。同一件事换个说法又说一遍、每段都收个小结论、
        通篇一个调子 —— 这些它看不见，得你自己读。
```

## 装

```sh
git clone https://github.com/hongdougao111/dsh-bagu.git
dsh plugin --profile web add link:/path/to/dsh-bagu
```

装完重启一次 dsh（宿主半侧和系统提示那一节都是启动时装配的）。

或者手动改 profile 的 `cordis.patch.yml`：

```yaml
- insert:
    - id: bagu
      name: dsh-bagu
      config:
        enabled: true
        prompt: true
        order: 921
```

## 边界

- **中文为主。**英文句子按同一套正则跑，但没专门校过英文。
- **基线取自中文评论语料。**写长文、写文档时会偏严 —— 那类文体本来就该有结构。
- **它只认字面。**通篇一个调子、每段都收个小结论、同一件事换个说法又说一遍，这些它看不见。
- **规则会过期。**今天有效的识别特征，被规则化之后就变成可学习、可识别的模式，
  接着就会被新的写法绕过。这个工具是止血带，不是解药。
