# dsh-bagu

> 名字来自「八股文」——那种格式对仗、内容空洞、谁都能写的东西。

## 一句话：它是干什么的

**你把一段话粘进去，它告诉你这段话里有没有「谁都能说」的成分。**

不改你的字，不给分数，只指出哪几处可疑，然后问你几个问题。

## 什么是「八股」

一句话，换个人说，还成不成立？

- 成立 → 就是八股。谁都能说的话，慢慢就没人想看了。
- 不成立 → 这段话里有只有你才给得出的东西。

看两个例子就懂了：

```text
差的：「本次修改已完成。首先调整了章节结构，其次新增了规则条款，最后优化了可读性。
      综上所述，这次改动具有重要意义。」

好的：「改了 AGENTS.md，加了 §4。第七页那个表我删了，因为原来那三列一直是空的。」
```

第一段把「AGENTS.md」换成任何文件名都通顺，所以它是八股。
第二段提到了第七页、提到了一个空表——别人编不出来。

## 它看哪四样东西

| 看什么 | 具体抓什么 | 为什么算数 |
|---|---|---|
| **具体物** | 数字、时间点、「我试过」、原话、专有名字 | 只有真在场的人才给得出 |
| **撑场面的话** | 意义 / 价值 / 本质 / 趋势，重要 / 关键 / 深刻 | 说得越多，越是在给事加光 |
| **留白词** | 好像 / 应该 / 大概 / 可能 | 一个都没有 = 句句在下断言 |
| **结构腔** | 不是A而是B、先…再…、三段并列、破折号 | 真人用，但密度极低，超基线才报 |

外加一个**同义轮换**：同一段里「使用 / 采用 / 运用」挑了两个以上。真人会反复用同一个词，换着说是心虚。

## 装

```sh
dsh plugin --profile web add dsh-bagu
```

装完重启一次 dsh。然后在**设置 → 八股检测**里能看到这一页。

## 怎么用

**方式一 · 让它自己查。** 你写完一段话，跟它说：

```
帮我查查这段有没有八股味
```

它会调 `bagu_check`，回三行：

```text
可疑  具体0 抽象1 评价1 留白0 结构0/千
· 综上所述
问 「综上所述」—— 这几个词，换成平时说话你会怎么讲？
```

想要详细报告，加一句「完整报告」，它传 `full: true`，会给逐处的命中位置和六条问句。

**方式二 · 只要问句。**

```
用 bagu_ask 问问我这段话
```

它只给问句，不给结论。答得上就留着，答不上来那处就是摆设。

**方式三 · 设置页里当场试。** 粘一段话点「查一下」，不发送、不落盘。

## 它不干什么

这几条先说清楚，免得期待错位。

**它不改写。** 一个字都不动。改是人的事，工具只把材料摆出来。

**它不给分数。** 没有「人味 62 分」这种东西。分数会让人只盯数字，不看句子。

**它不是体检报告。** 它管不了「整段是不是人写的」。通篇一个调子、每段都收个小结论、
同一件事换个说法又说一遍——这些它看不见，得你自己读。

**它是体温计，不是退烧药。** 测出来 49/千字，不会让你的话变好。真要让一段话立起来的是
真实经历、只有你知道的细节、真的想说的观点。这三样插件给不了，模型也长不出来。

**规则会过期。** 今天有效的识别特征，被写成规则之后，就成了可以绕过去的东西。
这是个止血带。

## 省 token 是怎么做的

这个插件从设计上就在控制上下文开销：

| 项 | 大小 |
|---|---|
| 系统提示注入 | 124 字（每次会话） |
| 两个工具的描述 | 62 字 |
| 默认输出 | 约 60 字（三行） |

所有判断都在本地正则里跑完，**不调模型**——这是零 token 成本的那一半。
要看详细报告才传 `full: true`，那时候才有几百字。

## 短句也能查

大部分「AI 味检测」靠密度（每百字几个），短句分母太小，等于废掉。

这个插件在六十字以下切换成**绝对计数**：不看密度，看命中了什么。
「不是A而是B」这种句式，出现在一句话里就已经可疑了，跟字数无关。

```text
「这不是技术问题，而是认知问题。」        → 可疑
「卖卡卖完了随便写了」                    → 正常
```

## 数据从哪来

权重和基线不是拍的。主要依据：

- 两轮对照实验，1169 篇 / 520 万字 / 100+ 项指标（[lieflat-less-ai-tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone)）
- 10 万条真人评论 vs 2180 条 AI 评论的密度实测
- [sloplint](https://github.com/DW-Studio/sloplint) 的评分公式（绝对命中 + 权重，短文本可用）
