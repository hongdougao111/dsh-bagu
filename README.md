# dsh-bagu

> AI 要对外说话之前的一道门。过了就发，没过就打回。

## 这是什么

用在所有「AI 写的东西要被人看到」的地方：

- **DSH 会话** —— agent 回复之前先过一遍
- **QQ 机器人 / 养鱼** —— 每条消息发出前
- **B站评论区、贴吧发帖** —— 公开回复

AI 在这些地方会写出这种话：

```
这条我认！首先态度要正，其次内容要实，最后要持续更新。
这个视频真的很不错，非常值得一看！
感谢分享！这个视频通过生动有趣的方式展示了相关内容，受益匪浅。
```

**这个插件在发出去之前拦一道。** 通过就发，没过就打回，附一句怎么改。

## 一句话判断

换个人说，还成不成立？成立，就是八股。

```text
「卖卡卖完了随便写了」        → 能发（编不出来）
「这个视频真的很不错」        → 打回（谁都能说）
```

## 怎么用

agent 每次要发消息之前，调一次：

```js
bagu_guard({ text: "这条我认！首先态度要正，其次内容要实，最后要持续更新。" })
→ "改：模板三连 · 直接说事，不用「首先其次最后」"
```

过了就回 `OK`，两个字。

**输出预算：通过 2 字，打回一行 40 字以内。** 每次都要烧 token，多一个字都是成本。

## 拦什么

按严重度排，只报第一条——报三条 agent 会挑最轻的改。

| 拦什么 | 例子 |
|---|---|
| 模板三连 | 首先…其次…最后… |
| 单列首先 | 「首先，我们需要明确目标。」 |
| 对举（四种写法） | 不是A而是B／不在于A而在于B／与其说A不如说B／看似A实则B |
| 反问式对举 | 难道这不是认知问题吗 |
| 套话整句 | 这条我认／本鱼记下了／感谢分享／受益匪浅／说白了就是 |
| 同义轮换 | 使用了新方法，采用了更好的方式 |
| 八股词 | 综上所述、底层逻辑、形成闭环、赋能 |
| 三段并列 | A、B、C 排一串 |
| 开头就总结 | 总之、总的来说 |
| 空夸 | 真的很不错，非常值得一看 |
| 同构短句排比 | 很强。很方便。很实用。 |
| 破折号 | ——（仅严格模式） |

## 实测三组数据

这套规则跑过三组样本，结果都在 `tools/` 里可复现：

| 测试 | 样本 | 结果 |

| AI 八股（客服腔／对举／空夸／模板） | 35 条 | 拦住 35（100%） |
| 真人原话（DSH 会话 + 贴吧 + 聊天） | 51 条 | 误拦 0（0%） |


## 它拦不住什么

对抗测试（`evasion.mjs`）里，10 种绕过手法拦住了 6 种。剩下 4 种是已知边界：

- **换同义词** —— 「功能多牛啊，用起来也顺手」，词换了形状没换，但不在表里
- **换成英文** —— 英文只做了留白词，句式没做
- **加脏话伪装** —— 「真他妈不错」，脏话把评价词淹了
- **去掉分组标记** —— 「目标是明确的，任务是拆过的，复盘也做了」

**规则只能认形状，认不了「这句话是不是真的」。** 这是一个止血带，不是解药。

## 跟 DSH 会话怎么接

DSH 有 `agent/pre-step` 这个 waterfall 钩子，能拿到本轮要发出去的 `messages` 并改它。
理论上可以在那里挂自动改写。**现在没有做**——`bagu_guard` 是个工具，靠 agent 自己调。

要真正变成自动门，得在插件里 `ctx.on('agent/pre-step', ...)` 拦一道。
那是下一步的事，不是现在。

## 装

```sh
dsh plugin --profile web add dsh-bagu
```

装完重启一次 dsh。**设置 → 八股检测** 里能看到这一页。

## 设置页

- **挡不挡** —— 总开关
- **多严** —— 正常只拦硬信号；严格连破折号、空夸也拦
- **提示那一节** —— 关掉只留工具，不往系统提示里塞话
- **试一段** —— 五种真实样本，当场看能不能过

## 一个工具，三种模式

```js
bagu_guard({ text })                    // 守门（默认），只回 OK 或一行改法
bagu_guard({ text, mode: 'report' })    // 详细报告，给人看
bagu_guard({ text, mode: 'ask' })       // 只要问句
```

三个原本是分开的工具，合成一个了——每多一个工具就多一份描述，每次都烧 token。

## 省 token 是怎么做的

| 项 | 大小 |
|---|---|
| 系统提示注入 | **31 字** |
| 工具描述（1 个） | **54 字** |
| 守门器输出 | 2 字（通过）／40 字内（打回） |

固定开销合计 **85 字**，判断全在本地正则里跑完，**不调模型**。

系统提示只有一句：「要发出去的话，先过 bagu_guard。被打回就改，别硬发。」
之前那四条写作建议删了——守门器自己会拦，提示里再教一遍是重复投资。

## 短句也能查

聊天回复二三十字是常态，密度指标在这个长度上分母太小。

六十字以下切换成**绝对计数**：不看密度，看命中了什么。

```text
「这不是技术问题，而是认知问题。」   → 打回
「卖卡卖完了随便写了」               → 能发
```
