# dsh-bagu

> AI 要对外说话之前的一道门。过了就发，没过就打回。

## 这是什么

凡是 AI 写的、要被人看到的东西，都可以先过一遍：

| 场景 | 例子 |
|---|---|
| **聊天** | QQ 机器人、养鱼、DSH 会话 |
| **评论** | B站、贴吧、微博、论坛 |
| **工作沟通** | 邮件、客服回复、周报 |
| **代码托管** | commit、PR 描述、review 评论、issue 回复、变更日志 |
| **文档** | README、技术文档、API 说明 |
| **代码** | 注释 |

这些地方 AI 会写出同一种东西：

```
这条我认！首先态度要正，其次内容要实，最后要持续更新。
感谢分享！这个视频通过生动有趣的方式展示了相关内容，受益匪浅。
feat: 优化了用户模块的代码结构，提升了可维护性
整体实现思路清晰，代码结构合理，建议后续可以进一步优化。
// 初始化计数器
注意看，这个男人叫小帅
```

**这个插件在发出去之前拦一道。** 通过就发，没过就打回，附一句怎么改。

## 怎么判断

一句话：**换个人说，还成不成立？**

```text
「卖卡卖完了随便写了」              → 能发（编不出来）
「这个视频真的很不错」              → 打回（谁都能说）
「登录失败时不再清空已填的手机号」   → 能发（具体到一行）
「优化了代码结构，提升可维护性」     → 打回（改哪一行？没说）
```

## 三层规则

### 第一层 · 通用（不分场景）

**空转** —— 说了动作，没说做了什么。

```
优化了代码结构 / 提升了可维护性 / 修复了若干已知问题 / 进行了必要的处理
```

**空形容词** —— 能贴到任何产品上的词。

```
先进的技术架构 / 高性能、高可用 / 具备良好的扩展性 / 能够满足业务发展的需要
```

**万能话** —— 放到哪都通顺。

```
随着人工智能的发展 / 众所周知 / 值得注意的是 / 不仅…更…
```

### 第二层 · 套话

**模板整句**：`这条我认` / `感谢分享` / `受益匪浅` / `说白了就是`
**鸡汤口号**：`愿你所行皆坦途` / `新的一天新的开始` / `努力不一定会成功`
**学习腔**：`学到了很多` / `涨知识了` / `希望以后多发这类帖子`
**视频开场白**：`注意看，这个男人叫小帅` / `话不多说，让我们直接进入正题` / `一键三连`

### 第三层 · 场景

**git**（commit / PR / review / issue / changelog）

```
feat: 优化了用户模块的代码结构          → 空转
## 概述 / ## 改动 / ## 影响            → PR 模板骨架
整体实现思路清晰，建议后续优化          → review 空话
感谢反馈！这个问题我们已经记录          → issue 客服腔
```

**代码注释** —— 把代码念一遍。

```js
// 初始化计数器            → 打回
let total = 0;
// 这里之所以要排序，是因为下游依赖顺序稳定的分页   → 能发
```

判据来自 [beagle style-criteria](https://github.com/existential-birds/beagle/blob/main/plugins/beagle-core/skills/llm-artifacts-detection/references/style-criteria.md)
和 [voku/code-slop](https://github.com/voku/agent-skills/blob/main/skills/code-slop/rules/comments-hygiene.md)：

> comments must explain **why**, never **what** the code already expresses.

## 引用和使用的区别

这是这道门最难判的一件事。

```text
「评论区一水儿「我记下了」」        → 在讨论这句话，不是用它 → 放过
「我记下了」                        → 直接用了 → 拦
「不要只说「受益匪浅」」             → 在批评，不是在使用 → 放过
「受益匪浅」                        → 真在拍马屁 → 拦
「一定会火＋求互关，雷踩得一个不落」  → 在点评别人的套话 → 放过
```

四条判据：

- **引号里**的内容不参与判断
- 套话前面有**否定词**（不要/别/避免）→ 在批评
- 套话前面有**指代词**（这句/这个/这条）→ 在指代前文
- 套话后面跟**评价词**（雷/反面教材/课后题）→ 在拿它当例子

## 可选：梗库与接梗

梗库判的是另一件事——「这个梗过气了没」「顺着这个能接什么」——
跟「谁都能说」无关，所以**默认关**。

```js
bagu_meme({ text: "这不就是瞎问虾猜那个系列吗" })
→ 对方提的是 瞎猜；同族还有 反向空耳、握着我的抱枕、七岁舔地砖、第四种速度

bagu_meme({ q: "社死" })
→ 社死：社死 是「社会性死亡」的简称…
```

数据来自 [梗Wiki](https://cnmeme.wiki) 的公开 API。`data/memes.json` 存了 120 条有完整锚点的词条。

**接梗的原理**：梗库的 keywords 在梗之间重叠，形成族。

```text
「瞎问虾猜」→ 反向空耳 / 握着我的抱枕 / 七岁舔地砖 / 第四种速度
「福本伸行」→ 超智游戏 / 斗牌传说 / 末世路
```

### AI 接梗：默认用会话自己的模型，不用填 key

梗库只给族，不给具体那句话。要让模型拼一句，开 `aiBridge`。

**默认走 DSH 会话自己的模型。**插件拿到当前会话的 provider/model，用宿主已经配好的连接，
**不用填 API key、不用填接口地址**——跟这个会话本身用的是同一个模型、同一份额度。

```text
对方说：这不就是瞎问虾猜那个系列吗
这段话涉及这些梗：瞎问虾猜
同族还可以提到：反向空耳、握着我的抱枕
→ 会话模型拼一句 25 字以内的接话
```

**另配接口是兜底。**只有在会话模型用不了时才需要开 `aiUseOwn`：
比如在 QQ 机器人里跑（没有 DSH 会话），或者想换更便宜的模型。

**调不通时自动退回本地族提示**（同族还有 A、B、C）。
没拿到路由、没有 llm 服务、stream 抛错、模型返空、返回超过 80 字，
任何一条都退回——不会因为模型挂了导致消息发不出去。

### 三种成本

| 场景 | 配置 | 成本 |
|---|---|---|
| 纯浏览 / 日常聊天 | 梗库关 | **0** |
| 想看能接什么 | 梗库开 | **0**（本地正则） |
| 要它替你想一句 | 梗库开 + AI 接梗开 | 每条一次会话模型调用 |

AI 接梗走会话模型，所以**不需要额外的 key**——用的是这个会话本身那一份额度。
另配接口那条路才要自己填 key。

### 贴吧那批语料为什么值钱

孙吧、v吧的真人说话充满了「八股规则看来可疑」的形状——

```text
反问：    你确定看不到过去的时间？兄弟
三段并列： 提瓦特世界是过去、现在、未来同时存在的
复述后反打：是啊，所以就静悄悄的也忘了
直接骂：   你放屁，分明是天理提供的
单字回复： 诶嘿 / 草 / 就这？
接梗：     那维莱特：新鞋，别搞
```

这些全是真人在说真话。68 条零误拦，说明规则没把这些当成套话。

## 它拦不住什么

对抗测试里 10 种绕过手法拦住了 6 种。剩下 4 种是已知边界：

- **换同义词** —— 「功能多牛啊，用起来也顺手」，词换了形状没换
- **换成英文** —— 英文只做了留白词，句式没做
- **加脏话伪装** —— 「真他妈不错」，脏话把评价词淹了
- **去掉分组标记** —— 「目标是明确的，任务是拆过的」

**规则只能认形状，认不了「这句话是不是真的」。** 这是止血带，不是解药。

## 长文也判

300 字以上不跳过——长邮件、长周报、长 PR 一样会八股。

但长文的门槛不同：同一个信号要出现**两次以上**才算，一次不算。

## 怎么用

```js
bagu_guard({ text: "这条我认！首先态度要正，其次内容要实，最后要持续更新。" })
→ "改：模板三连 · 直接说事，不用「首先其次最后」"

bagu_guard({ text: "登录失败时不再清空已填的手机号" })
→ "OK"
```

**三种模式：**

```js
bagu_guard({ text })                    // 守门（默认）
bagu_guard({ text, mode: 'report' })    // 详细报告，给人看
bagu_guard({ text, mode: 'ask' })       // 只要问句
```

**输出预算：通过 2 字，打回一行 40 字内。** 按严重度排，只报第一条——报三条 agent 会挑最轻的改。

## 省 token

| 项 | 大小 |
|---|---|
| 系统提示注入 | **31 字** |
| 工具描述（1 个） | **54 字** |
| 守门器输出 | 2 字（通过）／40 字内（打回） |

固定开销合计 **85 字**。判断全在本地正则里跑完，**不调模型**——
除了 AI 接梗那个单独开关。

## 短句也能查

聊天回复二三十字是常态，密度指标在这个长度上分母太小。
六十字以下切换成**绝对计数**：不看密度，看命中了什么。

```text
「这不是技术问题，而是认知问题。」   → 打回
「卖卡卖完了随便写了」               → 能发
```

## 装

```sh
dsh plugin --profile web add dsh-bagu
```

装完重启一次 dsh。**设置 → 八股检测** 里能看到这一页。

## 设置页

- **挡不挡** —— 总开关 / 严格模式 / 提示那一节 / 梗库
- **AI 接梗** —— 开关 + 显示当前会话的模型 + 另配接口（兜底）
- **试一段** —— 八种样本，当场看能不能过
- **阈值** —— 留白词下限、结构腔倍数、具体物下限
